# Sebara Wholesalers Website

🌐 **Live Site:** [www.sebara.co.za](https://www.sebara.co.za)

This is a modern and responsive website for **Sebara Mokone Wholesalers**, built using [Next.js](https://nextjs.org). The website showcases the business's products, contact information, and service offerings in a clean, user-friendly format. It is designed to be fast, mobile-responsive, and easy to maintain.

---

## 📌 Project Features

- ⚡ Fast and SEO-friendly website using Next.js
- 📱 Mobile-first responsive design
- 🎨 Clean UI/UX with modern layout
- 🧭 Simple navigation and contact section
- 🌐 Deployed live using Vercel

---

## 🚀 Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** JavaScript
- **Styling:** Tailwind CSS (if used)
- **Fonts:** [Geist](https://vercel.com/font) via `next/font`
- **Hosting:** Vercel
